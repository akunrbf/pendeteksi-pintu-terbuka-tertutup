# 🚪 Door State Detection AI

AI Computer Vision untuk mendeteksi kondisi pintu secara realtime menggunakan webcam.

Model AI mampu mengenali apakah pintu dalam kondisi **Terbuka** atau **Tertutup** secara otomatis langsung di browser.

---

## 🚀 Fitur

- ✅ Deteksi pintu realtime
- ✅ Status pintu: Terbuka / Tertutup
- ✅ Menggunakan webcam
- ✅ Running langsung di browser
- ✅ Tanpa backend server
- ✅ Model AI format ONNX

---

## 🧠 Kelas Deteksi

Model AI mengenali:

- 🚪 Door Open (Pintu Terbuka)
- 🔒 Door Closed (Pintu Tertutup)

---

## 🛠️ Teknologi Yang Digunakan

- HTML5
- CSS3
- JavaScript
- ONNX Runtime Web
- Roboflow
- WebCam API
- Computer Vision
